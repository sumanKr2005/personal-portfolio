## 📌 Project Overview

An interactive personal portfolio website showcasing my projects, skills,
and achievements as a Full Stack + GenAI Developer.

## ✨ Features

- Smooth navigation with animated hover effects
- Scroll-triggered animations (letter-by-letter, curtain split, 3D flip)
- Particle constellation background
- Custom cursor with magnetic hover
- Drag-scroll projects carousel
- Contact form with validation
- Fully responsive (mobile + tablet + desktop)

## 🛠️ Tech Stack

| Tech | Purpose |
|------|---------|
| HTML5 | Semantic structure |
| CSS3 | Flexbox, Grid, Animations, Media Queries |
| Vanilla JavaScript | Interactivity, Particles, Scramble |
| Font Awesome | Icons |
| Google Fonts | Inter + Space Grotesk |

## 📱 Sections

1. **Hero** — Name + rotating roles + animated card
2. **About** — Bio + education + stats
3. **Skills** — Tech stack (6 categories)
4. **Projects** — 4 real projects with drag carousel
5. **Experience** — Timeline with animated dots
6. **Achievements** — 3D flip cards
7. **Contact** — Form + info cards
